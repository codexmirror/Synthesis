# V0 scope

V0 is the responsive NODE-OS foundation for Synthesis. It contains a freshly created, versioned and sliced in-memory game state; a home launcher; shared status bars; and separate Terminal, Network, Wallet, Notes, Files, and System launcher apps. These apps describe the current interface, not a permanent product taxonomy.

Terminal supports command parsing, command history, and the `help`, `clear`, `ip`, `status`, and `scan <ipv4>` commands. Basic Scan V1 observes one IPv4 address in a tiny deterministic simulated network: an online host is identified as online, while offline and unrepresented valid addresses both produce `NO RESPONSE`. Invalid input is rejected. It does not discover ports, services, hostnames, ranges, or persistent player knowledge. The graphical Network app remains unavailable. Terminal output scrolls internally while its prompt remains outside that scrolling region. Notes persist locally through a feature-owned browser adapter, and the Notes textarea owns its scrolling. Files is a small virtual read-only listing.

On narrow or coarse-pointer layouts, focusing editable text activates a dedicated Editing presentation sized from the visible viewport. The shell changes its chrome and application presentation for keyboard use rather than allowing the entire shell to scroll; explicitly marked application regions own vertical scrolling. An opt-in viewport diagnostic (`?viewportDebug=1`) is retained for internal mobile investigation and is not player-facing gameplay.

Shell navigation remains outside game state. The current state is read-only after initialization: scanning is observational, with no gameplay mutations, saves or migrations. No backend, authentication, real networking, broader hacking, economy simulation, or multiplayer systems are included.

See [`ARCHITECTURE.md`](ARCHITECTURE.md) for the dependency and identity boundaries established by V0.
