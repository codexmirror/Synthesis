# V0 scope

V0 is a responsive browser shell for NODE-OS. It contains a shared player state, a home launcher, system status bars, and separate Terminal, Network, Wallet, Notes, Files, and System apps.

The terminal supports only `help`, `clear`, `ip`, and `status`. Notes persist locally in the browser; Files is a small virtual read-only listing. Network scanning is deliberately unavailable. No backend, authentication, real networking, hacking, economy, or multiplayer systems are included.
