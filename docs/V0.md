# V0 scope

V0 is the responsive, pre-gameplay NODE-OS foundation for Synthesis. It contains a freshly created, versioned and sliced in-memory game state; a home launcher; shared status bars; and separate Terminal, Network, Wallet, Notes, Files, and System launcher apps. These apps describe the current interface, not a permanent product taxonomy.

Terminal supports command parsing, command history, and only the `help`, `clear`, `ip`, and `status` commands. Its output scrolls internally while its prompt remains outside that scrolling region. Notes persist locally through a feature-owned browser adapter, and the Notes textarea owns its scrolling. Files is a small virtual read-only listing. Network displays an unavailable, disabled scan action; no scan operation exists.

On narrow or coarse-pointer layouts, focusing editable text activates a dedicated Editing presentation sized from the visible viewport. The shell changes its chrome and application presentation for keyboard use rather than allowing the entire shell to scroll; explicitly marked application regions own vertical scrolling. An opt-in viewport diagnostic (`?viewportDebug=1`) is retained for internal mobile investigation and is not player-facing gameplay.

Shell navigation remains outside game state. The current state is read-only after initialization: there are no gameplay mutations, saves or migrations. No backend, authentication, real networking, hacking, economy simulation, or multiplayer systems are included.

See [`ARCHITECTURE.md`](ARCHITECTURE.md) for the dependency and identity boundaries established by V0.
