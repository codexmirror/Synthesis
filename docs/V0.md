# V0 scope

V0 is the responsive NODE-OS interface for Synthesis. It contains a freshly created, versioned and sliced game state; a home launcher; shared system status bars; and separate Terminal, Network, Wallet, Notes, Files, and System features.

The terminal supports only `help`, `clear`, `ip`, and `status`. Notes persist locally through a feature-owned browser adapter; Files is a small virtual read-only listing. Network scanning is deliberately unavailable. Shell navigation remains outside the game state. No backend, authentication, real networking, hacking, economy simulation, or multiplayer systems are included.

See [`ARCHITECTURE.md`](ARCHITECTURE.md) for the dependency and identity boundaries established by V0.
