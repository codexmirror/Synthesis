# V0 scope

V0 is the responsive NODE-OS foundation for Synthesis. It contains a freshly created, versioned and sliced in-memory game state; a home launcher; shared status bars; and separate Terminal, Network, Wallet, Notes, Files, and System launcher apps. These apps describe the current interface, not a permanent product taxonomy.

Terminal supports command parsing, command history, and the `help`, `clear`, `ip`, `status`, `scan <ipv4|network-name>`, and `inspect <ipv4|network-name>` commands. Scan explores outward to discover relationships or connected targets; Inspect looks inward to report one target’s own properties. The current loop uses `ip`, scans that address to reveal the real `home-net` relationship, scans `home-net` to discover responding represented members, then inspects a discovered address. The network has a stable identity distinct from its name and canonical stable-ID membership containing the player's device and one real LAN host. Device identity is likewise distinct from its mutable IP address.

IPv4 scans distinguish `SELF` (the player-owned device), `LAN` (another device sharing a represented local network with SELF), and `REMOTE` (a represented device without that shared membership). A device Scan reveals real LocalNetwork relationships derived from canonical membership, while a network Scan discovers responding represented members and deterministically omits offline members. Both retain stable target identities internally while Terminal presents only current names and addresses. Device Inspect reports address, scope, online status, and self hardware where owned; it does not report membership. Network Inspect reports its current name and whether SELF is connected, without enumerating members. Scan observations and Terminal text are not entities or game state, and no persistent player-knowledge record is implemented; the loop targets real world objects directly. Target-token highlighting/copy interaction, ports, services, hostnames, ranges, server/access/filesystem gameplay, malware, scanner upgrades, and multiplayer remain unimplemented. The graphical Network app remains unavailable. Terminal output scrolls internally while its prompt remains outside that scrolling region. Notes persist locally through a feature-owned browser adapter, and the Notes textarea owns its scrolling. Files is a small virtual read-only listing.

On narrow or coarse-pointer layouts, focusing editable text activates a dedicated Editing presentation sized from the visible viewport. The shell changes its chrome and application presentation for keyboard use rather than allowing the entire shell to scroll; explicitly marked application regions own vertical scrolling. An opt-in viewport diagnostic (`?viewportDebug=1`) is retained for internal mobile investigation and is not player-facing gameplay.

Shell navigation remains outside game state. The current state is read-only after initialization: scanning and inspection are observational, with no gameplay mutations, saves or migrations. No backend, authentication, real networking, broader hacking, economy simulation, or multiplayer systems are included.

See [`ARCHITECTURE.md`](ARCHITECTURE.md) for the dependency and identity boundaries established by V0.
