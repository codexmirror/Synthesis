# V0 scope

V0 is the responsive NODE-OS foundation for Synthesis. It contains a freshly created, versioned and sliced in-memory game state; a home launcher; shared status bars; and separate Terminal, Network, Wallet, Notes, Files, and System launcher apps. These apps describe the current interface, not a permanent product taxonomy.

Terminal supports command parsing, command history, and the `help`, `clear`, `ip`, `status`, `scan <ipv4>`, and `inspect <ipv4>` commands. Scan and Inspect V1 form the current Network Analysis family: both resolve the current player-owned local device or a host in the tiny deterministic world network. The world also contains one real local network, whose canonical member-ID relation associates the player's device with it. Scan reports whether an IPv4 device target responds and its `LOCAL` or `REMOTE` scope. Inspect derives a responding local target's address, scope, status, CPU, RAM, and player-visible network name from current entity and relationship state; remote inspection reports only address, scope, and status because remote hosts contain no richer facts. Network names are distinct from stable network IDs. Network names are not accepted as targets, and network inspection, network scanning, member discovery, ports, services, hostnames, ranges, and persistent player knowledge remain unimplemented. The graphical Network app remains unavailable. Terminal output scrolls internally while its prompt remains outside that scrolling region. Notes persist locally through a feature-owned browser adapter, and the Notes textarea owns its scrolling. Files is a small virtual read-only listing.

On narrow or coarse-pointer layouts, focusing editable text activates a dedicated Editing presentation sized from the visible viewport. The shell changes its chrome and application presentation for keyboard use rather than allowing the entire shell to scroll; explicitly marked application regions own vertical scrolling. An opt-in viewport diagnostic (`?viewportDebug=1`) is retained for internal mobile investigation and is not player-facing gameplay.

Shell navigation remains outside game state. The current state is read-only after initialization: scanning and inspection are observational, with no gameplay mutations, saves or migrations. No backend, authentication, real networking, broader hacking, economy simulation, or multiplayer systems are included.

See [`ARCHITECTURE.md`](ARCHITECTURE.md) for the dependency and identity boundaries established by V0.
